## pip

创建 setup.py 文件

利用 setuptools

```python
from setuptools import setup, find_packages
 
setup(
    name="my_library",
    version="0.1.0",
    package_dir={"": "src"},  # 指定源代码目录
    packages=find_packages(where="src"),
    install_requires=[
        "requests>=2.25.1",  # 依赖项
        "numpy~=1.21.0"
    ],
    python_requires=">=3.8",
)
```

> 使用以下命令构建

生成 whl zip 相关压缩文件

```bash
python setup.py sdist bdist_wheel
```

> 测试

```bash
# 开发模式测试
pip install .

python -c "Python 代码"
```
## poetry

现代构建 pyproject.toml

```toml
[build-system]
requires = ["poetry-core>=2"]
build-backend = "poetry.core.masonry.api"
 
[project]
name = "my_library"
version = "0.1.0"
dependencies = [
    "requests >=2.25.1",
    "numpy ~=1.21.0"
]
```

> 使用构建命令

```bash
poetry build
```
