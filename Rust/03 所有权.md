## 值传递

Rust 中因为垃圾回收的机制，值只有一种传递方式
## 规则

- 一个值在同一个生命周期内只有一个所有者
- 实现了 Copy trait 的值，按照 Copy 浅拷贝，产生新值
- 一个值可以有多个只读引用
- 一个值可以有唯一一个活跃的可变引用
- 引用的生命周期不能超出值的生命周期（作用域内）
## 一个值有多个所有者

跳过编译器检查，运行时出错
### 单线程
#### Rc

> 引用计数，无法得到可变借用（clone 方式）

```rust
fn main() {
	let a = Rc::new(1);
	let b = a.clone();
	let c = a.clone();
}
```
#### RefCell

允许借用

```rust
fn main() {
	let a = RefCell:new(1);
	let b = a.borrow_mut();
}
```
### 多线程

#### Arc

```rust
let a = Arc::new(1);
let b = a.clone();
```

#### Mutex/RwLock

```rust
let a = Mutex::new(1);
```
